v1.5 Organization & Polish ⚡ In Progress Phase 4–6
◈ Advanced search (title, username, URL, tags)
◈ Category filter chips in vault
◈ Sort by: date, name, strength, category
◈ Tags system with multi-tag filter
◈ Trash / soft-delete with restore
◈ Clipboard auto-clear after 30 seconds
◈ PassForge → Save to Vault (direct integration)
◈ Auto-lock after inactivity (5 min)
◈ Keyboard shortcuts (N=new, /=search, Esc=close)
◈ Skeleton loading states
◈ Last copied indicator on cards
v2.0 Client-Side Encryption + Firebase Planned Phase 7–8
○ Master password + AES-256-GCM encryption of all vault entries
○ PBKDF2 key derivation (310,000 iterations)
○ Firebase Auth (email + Google login)
○ Firestore cloud sync (encrypted blobs only)
○ Email verification flow
○ Forgot password / reset
○ Session timeout + auto-lock
○ Zero-knowledge: server never sees plaintext
v2.5 Extra Vaults + Import/Export Planned
○ API Keys vault (key, service, expiry, scope)
○ WiFi Passwords vault
○ Recovery Codes vault
○ Import from Bitwarden JSON
○ Export encrypted JSON (re-importable)
○ Breach detection via HaveIBeenPwned API (k-anonymity)
v3.0 PWA + Offline + Polish Vision
○ Progressive Web App (installable)
○ Service worker + offline support via IndexedDB
○ Background sync when reconnected
○ Smooth page transitions and micro-animations
○ Full keyboard navigation
○ Architecture diagram in README
○ Security model documentation
